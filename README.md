# Wannabe My Valentine?
A fun and cute mini web project made with HTML, CSS, and JavaScript that asks the classic question:
"Will you be my Valentine?"

But beware — clicking "No" isn’t as easy as it sounds… because the button runs away! 😄

## Features
- Built with pure HTML, CSS, and JavaScript.

- "No" button evades the cursor when hovered over.

- "Yes" button shows a sweet success message.

- Simple, playful, and interactive design perfect for Valentine’s Day or just for fun!

## How to Use
Clone or download the repository:

```
git clone https://github.com/your-username/wannabe-my-valentine.git
```
Navigate into the project folder:

```
cd wannabe-my-valentine
```
Open index.html in your browser.
